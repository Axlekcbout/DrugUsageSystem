# Система учёта использования препаратов

Настольное приложение для Windows (C#, WinForms, .NET 8) для учёта применения лекарственных препаратов пациентами.

## Возможности

- Личные учётные записи сотрудников, вход по логину (пароль — PBKDF2-SHA256, 100 000 итераций)
- Карточки пациентов: ФИО, дата рождения, отделение, дата использования, препараты с дозировкой и датой применения
- Поиск, фильтрация (отделение, период, «только мои»), сортировка списка
- Передача карточки другому врачу
- Справочники отделений и препаратов (редактируются)
- Отчёты с пресетами периода, итогами и экспортом в Excel (XLSX)
- Роли: главврач (администратор) + должности (врач, медсестра, любая своя)
- Управление пользователями: добавление, смена логина и должности, удаление аккаунтов
- Резервное копирование и восстановление

## Запуск

1. Откройте `DrugUsageSystem\DrugUsageSystem.csproj` в Visual Studio 2022.
2. Нажмите F5. Пакеты NuGet не нужны — проект без внешних зависимостей.

База данных создаётся автоматически: `%LOCALAPPDATA%\DrugUsageSystem\drug_usage_data.json`.
Первый зарегистрированный аккаунт становится главврачом.

## Тесты

```bat
cd DrugUsageSystem.Tests
dotnet run -c Release
```

99 проверок ядра (хранилище, вход, роли, карточки, отчёты, XLSX, бэкапы, демо-данные).

## Особенности реализации

- Хранилище — JSON-файл (без SQLite), атомарное сохранение
- XLSX генерируется собственным мини-движком (ZIP + XML), без ClosedXML
- Весь интерфейс — программный код, без designer-файлов
